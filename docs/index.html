NovaKit

Installer en 3 étapes

HUD type Jarvis à partager. Télécharge le ZIP GitHub, lance l’installateur, puis crée ton IA au premier démarrage.

Télécharger depuis GitHub Voir le dépôt Clé Gemini

Chemin recommandé

  1. Télécharge & dézippe Sur GitHub → Code → Download ZIP, puis dézippe sur ton PC (Bureau, Documents…).
  2. Double-clique Installer NovaKit.bat Vérifie Python, installe les dépendances, puis propose de lancer l’app.
  3. Lance Lancer NovaKit.bat Au premier lancement, l’assistant te guide (pseudo, nom d’IA, clé Gemini).

Ce dont tu as besoin

Python 3

Depuis python.org — coche Add python.exe to PATH.

Clé Google Gemini

Gratuite via Google AI Studio — demandée au premier lancement.

Astuce

Préfère le ZIP source + les .bat plutôt qu’un exe trouvé ailleurs. Si Windows SmartScreen s’affiche : Plus d’infos → Exécuter quand même.
